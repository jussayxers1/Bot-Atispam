# Bot-Atispam
แจกบอท สำหรับการป้องกันการส่งข้อความที่เป็นไวรัส ลิ้งไวรัส รูป หรือจะเป็นไฟล์ สามารถบล็อคได้ทุกอย่าง
ลิ้งบอท
https://discord.com/oauth2/authorize?client_id=1524093738681630860&permissions=125952&scope=bot%20applications.commands

| คำสั่ง | คำอธิบาย |
|--------|----------|
| `/antispam-setup` | ติดตั้งบอทในเซิร์ฟนี้ และเลือกห้อง log |
| `/antispam-reload` | โหลดรายการโดเมน / คำสำคัญ / ลิงก์เชิญ / ไฟล์ / hash ใหม่ |
| `/antispam-addhash` | เพิ่มสแปมจากแคปรูป, ลิงก์ หรือไฟล์ **เฉพาะเซิร์ฟนี้** |
| `/antispam-addlink` | เพิ่มลิงก์สแปม **เฉพาะเซิร์ฟนี้** แล้วสแกนทั้งเซิร์ฟ |
| `/antispam-scan` | สแกนข้อความย้อนหลังทั้งห้อง หรือทุกห้อง แล้วลบสแปมที่ค้างอยู่ |
